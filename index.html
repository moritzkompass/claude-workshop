08 · Häufige Fragen

Was du als nächstes wissen willst.

Wenn deine Frage nicht dabei ist, antwortet Christian direkt. Kein Callcenter, keine Schleifen.

Was ist Claude Code überhaupt?
Claude Code ist eine Software von Anthropic, die direkt auf deinem Laptop läuft. Du sagst ihr in normalem Deutsch, was zu tun ist, und sie erledigt es: Mails schreiben, Angebote erstellen, Dokumente sortieren, Agenten bauen. Kein Programmieren nötig.
Brauche ich Vorwissen?
Nein. Wenn du E-Mails schreiben und einen Browser öffnen kannst, reicht das. Wir holen jeden bei Null ab.
Mac oder Windows?
Beides. Wir haben das Claude-Code-Setup für beide Betriebssysteme vorbereitet und betreuen dich individuell.
Was kostet Claude Code danach monatlich?
Für die meisten Setups 20 bis 50 € pro Monat. Wir besprechen das transparent und zeigen, wo es sich zahlt.
Sind meine Kundendaten sicher?
Wir behandeln das in Modul 1 ausführlich: was Anthropic mit deinen Daten macht, wie du sensible Inhalte anonymisierst und was du wo speichern darfst.
Kann ich zu zweit kommen?
Ja. Wer jemanden aus dem Betrieb mitbringt (Sohn, Bürokraft, Vorarbeiter), bekommt für beide je 200 € Rabatt.
Was, wenn ich's nicht hinbekomme?
Du gehst nicht raus, ohne dass Claude Code läuft. Falls das wider Erwarten passiert, gibt's einen kostenlosen 1:1-Folgetermin, bis es läuft.
Warum Claude Code und nicht ChatGPT?
ChatGPT chattet, Claude Code arbeitet. Es liest deine Dateien, schreibt Angebote in Word, beantwortet Mails in deinem Postfach, baut Agenten. Was Christian täglich nutzt, lernst du an dem Tag.
